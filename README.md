# Erikvanzijst Tap

## How do I install these formulae?

`brew install erikvanzijst/tap/<formula>`

Or `brew tap erikvanzijst/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "erikvanzijst/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
